# SECCON Beginners 2026 Writeup

SECCON Beginners 2026 に参加した際のWriteupをまとめたリポジトリです。
大会中にHackMDへ各自がリアルタイムで残したメモを、大会後に整理・加筆したものを格納しています。

## 概要

- **対象大会**: SECCON Beginners CTF 2026
- **参加形態**: チーム参加(小出研究室 CTF勉強会メンバー)
- **目的**:
  - 解いた問題・解けなかった問題の振り返り
  - 同じジャンルの問題に取り組む後輩・メンバーへの参考資料
  - 来年以降のSECCON Beginners対策の蓄積

## ディレクトリ構成

ジャンルごとにディレクトリを分け、その中に問題ごとのMarkdownファイルを置いています。

```
.
├── crypto/

│   └── AES-revenge.md
├── web/

```

## 各Writeupの記載内容

各ファイルには、以下の項目を基本フォーマットとして記載しています。

- **問題概要**: 配布ファイル、問題文の要約、ジャンル・難易度
- **やったこと**: 調査・試行錯誤の過程(詰まった点やボツになったアプローチも含む)
- **解法**: 最終的に解けた手順、使用したスクリプト・コマンド
- **フラグ**
- **学び・教訓**: 今回の問題で得られた知識や、次回以降に活かせるポイント

未解決だった問題についても、どこまで進んだか・何が壁になったかを残しています。

## 関連リンク

- 大会中の進捗管理・問題分担には別途スプレッドシートを使用しました
- 各ジャンルの大会中メモはHackMDで作成し、本リポジトリへ移行・整理しています

## ライセンス

特記なき限り、本リポジトリの内容は学習・参考目的での利用を想定しています。
問題の配布ファイルや問題文自体の著作権は主催者(SECCON運営)に帰属します。
