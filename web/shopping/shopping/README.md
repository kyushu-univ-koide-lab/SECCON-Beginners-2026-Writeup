# coupon-stash

Small coupon shop challenge for ctf4b.

## Run

```bash
docker compose up --build
```

The app listens on `http://localhost:8000`.

## Player Info

- Initial points: `0 pt`
- Coupon code: `SPECIAL_VOUCHER_FOR_CTF4B`
- The coupon gives points after the statement is prepared.
- Items are exchanged with exchange codes. Cheap items can be exchanged normally with the shared exchange form.

Each browser receives its own anonymous wallet. Use `New wallet` if you want to start over.
